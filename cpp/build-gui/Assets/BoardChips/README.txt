BOARD CHIP IMAGES (TV display)
==============================

Optional folder of chip images for Tournament Settings → Board chips.

You can:
  1. Pick a file from this folder in the Image dropdown, or
  2. Use Browse… to select any image filepath on disk.

Examples in this folder:
  white.png, red.png, chip_1.png, plaque_25.png, …

Recommendations:
- Square PNGs with transparent background
- At least 128×128 pixels
